## 🧮 Example Problem

### 🏨 Hotel Cost Calculator
A C program that calculates the **minimum hotel cost** for a customer based on:
- Number of adults and children  
- Room type (1, 2, or 3)  
- Number of days  

Each room can hold up to **2 adults + 2 children**.  
Extra children beyond room capacity are charged **৳500 per head**.
